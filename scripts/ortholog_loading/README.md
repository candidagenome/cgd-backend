# C. glabrata Transitive Ortholog Loading

Scripts to load transitive orthologs derived from YGOB (C. glabrata <-> S. cerevisiae)
and CGOB (S. cerevisiae <-> Candida) data.

## Background

Transitive orthology relationship:
```
C. glabrata Gene A <=> S. cerevisiae Gene B (YGOB)
S. cerevisiae Gene B <=> C. albicans Gene C (CGOB)
=> C. glabrata Gene A <=> C. albicans Gene C (transitive)
```

## Prerequisites

1. Transitive orthologs file must exist:
   ```
   /data/cgob/cglabrata_transitive_orthologs.tsv
   ```

2. This file is generated by:
   ```
   /data/cgob/parse_transitive_orthologs.py
   ```

## Usage

### Quick Start

```bash
cd /home/ec2-user/work/cgd-backend/scripts/ortholog_loading
chmod +x run_ortholog_loading.sh

# Run validation
./run_ortholog_loading.sh validate

# Preview loading (dry-run)
./run_ortholog_loading.sh load

# Actually load data
./run_ortholog_loading.sh load-real
```

### Step-by-Step

#### 1. Validate Transitive Orthologs

```bash
source /home/ec2-user/work/cgd-backend/venv/bin/activate
cd /home/ec2-user/work/cgd-backend

python scripts/ortholog_loading/validate_transitive_orthologs.py \
    --input /data/cgob/cglabrata_transitive_orthologs.tsv \
    --output /data/cgob/validation_report.tsv
```

This generates:
- `validation_report.tsv` - Full report with status for each mapping
- `validation_report_additions.tsv` - List of feat_homology records to create

#### 2. Review Validation Report

Check the summary output and review the status categories:
- `already_in_group` - C. glabrata already in CGOB group (no action needed)
- `add_to_group` - C. glabrata should be added to existing CGOB group
- `no_cgob_group_for_ortholog` - Ortholog not in any CGOB group
- `ortholog_feature_not_found` - Ortholog gene not found in database
- `cg_feature_not_found` - C. glabrata gene not found in database

#### 3. Load Additions (Dry Run)

```bash
python scripts/ortholog_loading/load_transitive_orthologs.py \
    --additions /data/cgob/validation_report_additions.tsv \
    --dry-run
```

#### 4. Load Additions (Real)

```bash
python scripts/ortholog_loading/load_transitive_orthologs.py \
    --additions /data/cgob/validation_report_additions.tsv \
    --verify
```

## Database Changes

The loading script creates records in `MULTI.feat_homology` table:
- Links C. glabrata features to existing CGOB homology groups
- Uses `created_by = 'ygob_trans'` for audit trail

## Verification

After loading, verify via SQL:
```sql
SELECT COUNT(*)
FROM MULTI.feat_homology fh
JOIN MULTI.feature f ON fh.feature_no = f.feature_no
WHERE f.feature_name LIKE 'CAGL%'
AND fh.created_by = 'ygob_trans';
```

Or check a specific gene on the locus page in the web interface.

## Files

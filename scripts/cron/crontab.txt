# =============================================================================
# CGD CRON JOBS (UTC times)
# =============================================================================
#
# Note: These times are in UTC. The offset from Pacific time varies:
#   - PST (Nov-Mar): UTC = PST + 8 hours
#   - PDT (Mar-Nov): UTC = PDT + 7 hours
#
# These cron times are set for PST (+8). During daylight saving time (PDT),
# jobs will run 1 hour later in local Pacific time.
#
# -----------------------------------------------------------------------------
# PREREQUISITES
# -----------------------------------------------------------------------------
#
# The following tools must be installed on the production server:
#
#   Python environment:
#     - Python 3.9+ with venv at /opt/cgd_api/.venv
#     - All dependencies from requirements.txt
#
#   Playwright (for smoke tests):
#     - playwright package installed in venv
#     - Chromium browser: playwright install chromium
#     - System dependencies: playwright install-deps chromium
#
#   Bioinformatics tools (for JBrowse2 update):
#     - samtools: For FASTA indexing (faidx)
#       Install: sudo yum install samtools (Amazon Linux) or conda install samtools
#     - htslib: For bgzip compression and tabix indexing
#       Install: sudo yum install htslib (Amazon Linux) or conda install htslib
#
#   Other:
#     - curl: For Slack notifications (slack-cron.sh)
#     - mail/sendmail: For email reports (curator_reports.py)
#
# =============================================================================

# -----------------------------------------------------------------------------
# MONITORING (Every 10 minutes - runs as root)
# -----------------------------------------------------------------------------
#
# Memory monitoring and auto-restart:
#   - Checks system memory usage percentage
#   - Checks largest gunicorn worker memory
#   - Restarts cgd-api service if:
#     * System memory > 80%
#     * Any single worker > 4GB (indicates memory leak)
#   - Logs to /opt/cgd_api/logs/monitor.log
#
# Note: This runs as root via /etc/cron.d/cgd-api-monitor (not in user crontab)
#       because it needs privileges to restart the systemd service.
#
# Installation:
#   echo '*/10 * * * * root /opt/cgd_api/scripts/cron/cgd_monitor_memory.sh' | sudo tee /etc/cron.d/cgd-api-monitor
#
# */10 * * * * root /opt/cgd_api/scripts/cron/cgd_monitor_memory.sh

# -----------------------------------------------------------------------------
# TWICE DAILY (7 AM and 7 PM UTC)
# -----------------------------------------------------------------------------

# Curl-based smoke tests - quick API and page health checks:
#   - Uses curl to check HTTP responses (no browser needed)
#   - Verifies API endpoints return expected JSON fields
#   - Verifies frontend pages return expected HTML content
#   - Sends Slack notification on failure
#
# API endpoints tested:
#   - Health check, Locus (ACT1), GO details, Phenotype details
#   - Sequence details, Protein details, GO term, Search autocomplete
#   - Reference endpoint
#
# Frontend pages tested:
#   - Home, Locus, GO term, Feature search, BLAST, Phenotype search
#
# Note: Uses --api-only since frontend is React SPA (use Playwright for frontend)
#       Uses localhost for API since external URL not reachable from server
0 7,19 * * * cd /opt/cgd_api && set -a && source .env && set +a && CGD_API_URL=http://localhost:8000/api ENV_STATE=prod scripts/cron/cgd_smoke_tests.sh --api-only 2>&1 | head -50

# -----------------------------------------------------------------------------
# EVERY 6 HOURS (Health checks)
# -----------------------------------------------------------------------------

# Playwright smoke tests - verify frontend JavaScript rendering:
#   - Loads pages in headless Chromium browser
#   - Waits for JavaScript content to render
#   - Verifies expected text and elements appear
#   - Sends Slack notification on failure
#
# Pages tested:
#   - Home page
#   - Locus page (ACT1) with all tabs (GO, Phenotype, Sequence)
#   - GO term page
#   - Feature search, BLAST, Phenotype search pages
#   - Reference page
#
# Note: Requires Playwright and Chromium installed (see Prerequisites)
0 */6 * * * cd /opt/cgd_api && set -a && source .env && set +a && source .venv/bin/activate && CGD_WEB_URL=https://www.candidagenome.org ENV_STATE=prod python scripts/cron/cgd_playwright_tests.py 2>&1 | head -50

# -----------------------------------------------------------------------------
# DAILY RUNS (Every day)
# -----------------------------------------------------------------------------

# Run API test suite and send Slack report:
#   - Runs pytest on API tests (tests/api/)
#   - Reports passed/failed/skipped counts
#   - Lists failed test names in Slack notification
#   - Logs stored in ${LOG_DIR}/test-results/
#
# Test Coverage (~1400 tests across 40 modules):
#   Public API Services:
#     - Search: full-text search, feature search, database search
#     - Features: locus details, sequences, GO annotations, phenotypes
#     - References: literature data, batch downloads
#     - Tools: BLAST, PatMatch, restriction mapper, web primer designer,
#              sequence alignment, GO Term Finder, GO Slim mapper
#     - Genome: chromosome details, coordinate lookup, genome versions
#   Curation Services:
#     - Locus curation: gene names, aliases, descriptions, notes
#     - Literature: review queue triage, literature guide associations
#     - GO curation: annotation management with evidence codes
#     - Phenotype curation: observable/qualifier/experiment handling
#     - Reference curation: PubMed import, manual entry, status tracking
#     - Sequence curation: coordinate and sequence updates
#     - Colleague/gene registry: submissions and approvals
#   Infrastructure:
#     - Elasticsearch indexing and search
#     - Batch download generation (GAF, GFF, FASTA)
#     - Form submission utilities
#
# Usage:
#   ./cgd_run_tests.sh           # Run API tests only (default, more reliable)
#   ./cgd_run_tests.sh --all     # Run all tests including script tests
#   ./cgd_run_tests.sh -k "go"   # Run tests matching "go"
#
# Note: Runs early morning to catch any regressions before curators start work
0 1 * * * cd /opt/cgd_api/scripts/cron && ./cgd_run_tests.sh

# Update ORF classifications based on GO annotation evidence codes:
#   - Verified: has GO annotation with experimental evidence (not IEA/ISS/RCA/ISA/ISM/ISO/NAS/ND)
#   - Uncharacterized: not deleted, not dubious, lacks strong GO evidence
# Note: Dubious status is assigned manually by curators, not by this script
0 2 * * * cd /opt/cgd_api/scripts/cron && ./slack-cron.sh ./cgd_update_orf_classifications.sh

# Check data integrity and business rules, email violations to curators:
#   - Duplicate URL types per feature
#   - Gene reservations with missing colleague emails
#   - Locus name vs alias name conflicts
#   - Pseudogenes with GO annotations (should have none)
#   - Headlines linked to both auto-generated and manual references
#     (The "auto-generated ref" is internal reference_no 56824, used when
#     headlines are derived from S. cerevisiae orthologs or transferred GO)
0 3 * * * cd /opt/cgd_api/scripts/cron && ./slack-cron.sh ./cgd_check_data.sh

# Dump GO annotations to GAF 2.0 format (gene_association.cgd) for GO Consortium
0 4 * * * cd /opt/cgd_api/scripts/cron && ./slack-cron.sh ./cgd_dump_annotation.sh

# Dump GO Slim annotations (GOslim_gene_association.cgd) mapping GO terms to slim categories
0 5 * * * cd /opt/cgd_api/scripts/cron && ./slack-cron.sh ./cgd_dump_go_slim_annotation.sh

# Make GO-complete: assign root GO terms (GO:0008150, GO:0003674, GO:0005575)
# with ND evidence to features lacking annotations in each aspect (P, F, C)
0 6 * * * cd /opt/cgd_api/scripts/cron && ./slack-cron.sh ./cgd_make_go_complete.sh

# Weekly PubMed update pipeline:
#   - Search PubMed by species name (e.g., "Candida AND albicans") and load new references

# Update JBrowse2 data files from GFF and sequence dumps.
#
# What it does:
#   1. Takes GFF files from ${DOWNLOAD_DIR}/gff/
#   2. Sorts by chromosome and position
#   3. Compresses with bgzip and creates tabix index
#   4. Takes FASTA files from ${DOWNLOAD_DIR}/sequence/
#   5. Decompresses and creates samtools faidx index
#   6. Outputs to ${JBROWSE_DIR} (default: /data/jbrowse2/)
#
# Species handled:
#   - C_albicans_SC5314 (Assembly 22)
#   - C_dubliniensis_CD36
#   - C_glabrata_CBS138
#   - C_parapsilosis_CDC317
#   - C_auris_B8441
#
# Note: Runs after GFF dump; gracefully handles missing FASTA until monthly dump
0 8 * * 0 cd /opt/cgd_api/scripts/cron && ./slack-cron.sh ./cgd_update_jbrowse.sh
